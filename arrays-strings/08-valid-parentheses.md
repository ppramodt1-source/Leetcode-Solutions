# Problem: Valid Parentheses

**Difficulty:** Easy

**Link:** https://leetcode.com/problems/valid-parentheses/

## Approach

I used a stack to store the opening brackets.
For every closing bracket, I checked whether it matches the top opening bracket.

## Complexity

- Time: O(n)
- Space: O(n)

## Notes

Learned how a stack can be used to match opening and closing brackets.
