# Problem: Valid Anagram

**Difficulty:** Easy

**Link:** https://leetcode.com/problems/valid-anagram/

## Approach

I sorted both strings and compared them.
If both sorted strings are the same, they are anagrams.

## Complexity

- Time: O(n log n)
- Space: O(1)

## Notes

Learned how sorting can be used to check whether two strings are anagrams.
