# Problem: Binary Search

**Difficulty:** Easy

**Link:** https://leetcode.com/problems/binary-search/

## Approach

I used two pointers, left and right, to search the middle element.
Based on the target, I searched either the left or right half of the array.

## Complexity

- Time: O(log n)
- Space: O(1)

## Notes

Learned how binary search reduces the search area by half each time.
