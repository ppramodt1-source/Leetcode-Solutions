# Problem: Move Zeroes

**Difficulty:** Easy

**Link:** https://leetcode.com/problems/move-zeroes/

## Approach

I moved all non-zero elements to the front of the array.
After that, I filled the remaining positions with zeroes.

## Complexity

- Time: O(n)
- Space: O(1)

## Notes

Learned how to move zeroes to the end while keeping the other elements in the same order.
